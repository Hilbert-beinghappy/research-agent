# v1.0 long-running public replays

These replay specifications identify two non-toy, redistribution-safe project tracks used to compose the complete personal research release matrix across repeated Pi Sessions. They reuse the recorded provider/PDF fixtures and synthetic method/material/manuscript assets already shipped in `examples` and `test/fixtures`; they are not prebuilt canonical project snapshots and do not claim empirical findings about real people or organizations.

`projects.json` maps each project to its public topic, required lifecycle stages, minimum Session count, and release gates. Scenario A creates and validates the canonical projects in temporary directories. Extension integration reopens a project across ten Session identities. Scenario D upgrades every historical schema at three interruption boundaries, verifies its backup, and restores the old root exactly. Clean-install tests pack and load the package against both supported Pi versions.

Corpus-scale performance is a separate deterministic 10,000-source/50,000-evidence benchmark so the repository does not duplicate 60,000 generated canonical files. The release evidence therefore distinguishes workflow-complete projects from the scale fixture.

Generated project IDs, timestamps, machine paths, credentials, raw provider sessions, and runtime logs are never committed.
