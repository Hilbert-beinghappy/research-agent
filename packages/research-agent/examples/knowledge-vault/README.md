# Synthetic knowledge export

This directory shows the readable shape of an unpacked v0.5 Obsidian export. It is derived output, not a hand-editable replacement for `research-project.json` or `.research/records`.

`profile.json` stores a credential alias, never a token. A live Zotero push requires destination-bound approval and creates ExternalItemLink reconciliation records in the canonical project; this example performs no network call.
